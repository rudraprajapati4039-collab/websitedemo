NISHTHA ENTERPRISE CSC - HOW TO RUN
1. Install Node.js (version 18 or newer) from nodejs.org
2. Open this folder in a terminal and run:  npm install
3. Start the site:  npm start
4. Public site:  http://localhost:3000        CSC login:  http://localhost:3000/login.html
Admin login: phone 8200608242, password as given (change it before going live:
set ADMIN_PHONE and ADMIN_PASS environment variables before the FIRST run).
Add your own shop photos as public/images/1.jpg, 2.jpg, 3.jpg.
Customer documents are saved in the "uploads" folder and the data in cse.db (back these up).

NEW: In the CSC panel (Website settings) you can change the home page background picture,
add/remove services and add/remove gallery photos. Pictures are saved in the "site-images" folder.
